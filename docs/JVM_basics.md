# ☕ JVM Basics – LearnTrack Project

This document explains the basic Java runtime concepts used while building the LearnTrack application.

---

## What is JDK, JRE, JVM?

- **JDK (Java Development Kit):** The JDK is a complete software development kit required to develop Java applications. It includes the Java compiler (`javac`), Java Runtime Environment (JRE), and various development tools. Without the JDK, you cannot compile Java programs.

- **JRE (Java Runtime Environment):** The JRE provides the libraries, Java Virtual Machine (JVM), and other components to run applications written in Java. It is required to run Java programs but does not contain tools for Java development like the compiler.

- **JVM (Java Virtual Machine):** The JVM is the engine that executes Java bytecode. It loads, verifies, and executes the compiled Java code, manages memory, and handles garbage collection. The JVM makes Java platform-independent by providing a consistent execution environment across different operating systems.

---

## What is Bytecode?

Bytecode is an intermediate, platform-independent code generated by the Java compiler from source code (`.java` files). This bytecode (`.class` files) is not specific to any processor or operating system. Instead, it is executed by the JVM, which interprets or compiles it into native machine code at runtime.

Example:
```bash
   javac Main.java
```
This command compiles `Main.java` into `Main.class` (bytecode), which the JVM can execute.

---

## What does “write once, run anywhere” mean?

“Write once, run anywhere” is a core philosophy of Java. It means that once you write and compile a Java program into bytecode, you can run it on any device or operating system that has a compatible JVM. You do not need to modify or recompile your code for different platforms.

This is possible because the JVM abstracts away the underlying hardware and operating system details. As a result, Java applications are highly portable, making them suitable for a wide range of environments, from desktops to servers to embedded systems.

---

## How Does the JVM Work in LearnTrack?

- The JVM loads and runs the compiled `.class` files of the LearnTrack application.
- It manages memory for objects like students, courses, and enrollments.
- Handles exceptions and garbage collection automatically.

---

## Why Is This Important?

Understanding the JDK, JRE, and JVM helps in:
- Debugging issues
- Optimizing performance
- Ensuring portability of the LearnTrack application
